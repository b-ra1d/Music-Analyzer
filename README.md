# Music Analyzer

**Music Analyzer** — это многостраничное веб-приложение для поиска, анализа и прослушивания музыкальных треков.  
Проект разработан с использованием HTML, CSS и чистого JavaScript без фреймворков и демонстрирует работу с внешними API, асинхронными запросами и пользовательской логикой.

## 📌 Основные возможности

- Поиск треков и исполнителей через **Deezer API** (подключение через CORS-прокси)
- Просмотр подробной информации о треке (название, артист, альбом, длительность)
- Воспроизведение аудиопревью треков
- Добавление и удаление треков в избранное
- Сохранение данных в `localStorage` (избранное, тема, статистика поиска)
- Статистика поиска и избранного
- Адаптивный дизайн для ПК и мобильных устройств

## 🧰 Используемые технологии

- HTML5
- CSS3 (градиенты, прозрачные карточки, тени, hover-эффекты)
- JavaScript (ES6+)
  - fetch API
  - async / await
  - управление аудиоплеером
  - localStorage

## ⚙️ Как запустить

1. Открой проект через локальный сервер (рекомендуется):
   - Через Python:
     ```bash
     python -m http.server 8000
     ```
   - Через Live Server в VS Code
2. Открой браузер и перейди на:
http://localhost:8000
3. В поиске вводи название трека или исполнителя, чтобы отобразить результаты.

> ⚠️ Важно: Deezer API используется через CORS-прокси, поэтому работа может зависеть от доступности прокси.

## 🎓 Особенности реализации

- Глобальный аудиоплеер: только один трек играет одновременно
- Избранное хранится в localStorage и сохраняется между перезагрузками
- Адаптивный дизайн: карточки треков, аудиоплеер и input подстраиваются под экран
- В проекте продемонстрирована работа с внешним API, асинхронным кодом и управлением состоянием приложения

## 📌 Примечание для преподавателя

Проект построен по современным принципам frontend-разработки:
- отделение логики (JS) от разметки (HTML)
- работа с публичным API
